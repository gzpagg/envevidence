# 技术结构

[English](ARCHITECTURE.md)

EnvEvidence 是 Python＋Streamlit 单用户本地应用。CLI 和原有证据流程与 v0.1 兼容。

## 数据边界

文献 Project JSON 保持 schema_version 1；解析、模型适配、原句定位、人工核验和导出为独立模块。Workspace 包含偏好设置；自 0.3 起仅保留 0.2 的学习目标与步骤、日期任务和便利贴数据，使原文件可原样读取和保存，界面不再显示或编辑。独立保存在数据目录的 workspace/state.json，不参与文献项目发现。

保存使用同目录临时文件、flush/fsync 和原子替换；读取或验证失败时保留原文件。不提供并发编辑合并或云同步。

## 界面与网络

ui.py 为入口；workbench_ui.py 负责侧栏与外观页，evidence_ui.py 负责证据流程。控件用稳定 ID；语言上下文和格式化函数只改变应用文字与已知诊断显示，不改写用户输入或科研记录。

配色使用验证过的十六进制颜色和应用 CSS，不调用私有主题 API。前景色按对比度选择，原生控件保持中性。语言与配色均持久化。

仅在界面确认发送或 CLI 显式指定 --send-text 后向官方端点发送文献文本。每完成一项研究即保存。模型原值与人工修订分别保留；原句定位不证明科学结论正确。

当前没有 OCR、图像读数、自动单位换算、外部模块加载、账号系统或多人编辑。实验计时与样品记录在独立的 EnvBench 安卓应用中。
