# 技术结构

[English](ARCHITECTURE.md)

仓库包含两个本地应用：Python＋Streamlit 实验分析与文献证据工具 **EnvEvidence 0.4.0**，以及安卓实验手记 **EnvBench 0.6.1**。两者共用开源仓库，通过明确的导出／导入流程连接数据，各自维护运行时存储。

## 电脑版实验分析流程

实验 `AnalysisProject` 使用独立的 schema version 1，保存数据系列、定量测量、不可变来源描述、处理与绘图设置、拟合请求／结果、手机档案和审计历史。项目位于数据根目录的 `analysis/<project-id>/`。原文件按内容寻址并保存 SHA-256，手动录入保留初始输入快照，JSON 使用临时文件与原子替换保存。

`analysis_data.py` 负责严格输入验证、表格／手机导入、按样品编号关联检测结果、单位分类、处理阶段和技术重复汇总。处理保留全部观测及纳入标记／理由；技术重复仅在同一 run、样品和自变量值内汇总，独立实验编号分别保留。手机 ZIP 解压前检查路径与展开大小，导入快照保存实验历史及照片。

`analysis_fitting.py` 负责原始尺度与适用线性化模型。SciPy 使用有界 float64 拟合，对速率与平台参数施加物理约束；目标和已提供 sigma 同时缩放，使数值容差不依赖响应单位，输出仍使用物理单位。固定值减少自由参数，每次至少四点且满足 p+2。无效的纳入数据会停止拟合，秩、条件数、相关性、边界和响应变化用于区间诊断。预测与残差保留各 run 的点集标记。

`analysis_export.py` 生成指定尺寸的 Matplotlib 图片、CSV／XLSX 数据表和独立 ZIP。物理尺寸与 DPI 计算栅格像素，预先限制分配大小；随附 Noto 字体提供中文字形，SVG 使用轮廓。确认结果用于成果图，候选拟合仍完整留在表中。清单保存校验值、版本和字体来源，配置保存相对原文件路径及完整处理／拟合快照。

新增 `analyze --config … --output …` CLI 验证原文件校验值，在独立存储中恢复资料、重算处理和拟合、恢复确认标记并生成新成果包。原有 `serve`、`demo`、`extract` 保持兼容。实验项目界面由反应条件、测量数据、数据处理、动力学拟合、图表格式和 SOP 导出构成，语言／外观统一管理。

## 电脑版证据流程

文献 `Project` JSON 保持 schema version 1，文档解析、模型适配、原句定位、人工核验和导出为独立模块。CLI 保持原有证据流程兼容。

`Workspace` schema version 1 保存语言与外观偏好，同时保留 0.2 的学习目标、任务和便签，使旧文件可原样读取与写回。文件位于数据目录的 `workspace/state.json`，不参与证据项目发现。

保存使用同目录临时文件、flush/fsync 与原子替换，读取或验证失败时保留原文件。同一项目使用一个编辑进程。

`ui.py` 提供入口，`workbench_ui.py` 负责侧栏与外观页，`analysis_ui.py` 负责实验流程，`evidence_ui.py` 负责证据流程。稳定 ID 用作控件键，逐次渲染的语言上下文改变界面文字而保留科研内容和审计记录。配色使用经过验证的十六进制颜色与应用 CSS，前景色按对比度选择。

OpenAI 与 Anthropic 适配器在界面确认发送或 CLI 使用 `--send-text` 后调用官方端点。每完成一项研究独立保存，模型原值与人工修订分别保留。

## 安卓实验手记

内置 HTML/CSS/JavaScript 通过 WebViewAssetLoader 运行。`lab-domain.js` 保存实验、计时、样品、水质与计算规则；`lab.js` 提供实验手记交互，`bench.js` 提供反应界面。Java 桥接私有存储、安卓时钟、闹钟、通知、相机／文件和 ZIP 操作。

Lab schema version 2 保存实验、计时器、计数器、现象、事件与样品。升级补齐样品审计字段并保留旧数据，旧版非空测量值标为来源未知，不追溯伪标为实测。

样品修订保留原数值、测量来源、时间间隔和理由。原始按钮事件的时间戳保持不变，修订后的实验时长用于取样偏差、拟合与辐照剂量。CSV 保持稳定机器字段名并增加审计列，完整 ZIP 保留全部历史和原始照片。

峰面积导入先验证整批数据，再统一应用。带编号与按顺序格式分别处理，错误保留原行位置。拟合使用正的、未排除的比值；排除保留理由，曲率只作为模型偏离诊断。

同一次设备启动期间使用安卓单调时钟，重启或换机后使用保存的系统时间恢复。导入的运行中计时器保持暂停。

## 数据边界

安卓实验功能在本机运行，照片与手记保存在私有目录。电脑版文献提取向所选服务发送解析文本与字段说明，密钥不写入项目 JSON。运行数据、API 密钥和私有签名材料排除在 Git 与源码包之外。

EnvBench CSV／ZIP 快照单向导入电脑实验分析，通过样品编号关联检测结果，手机原始时间戳与历史保留。文献项目继续使用独立格式与存储。实验分析不调用模型，只有主动文献提取才经过 API 边界。
