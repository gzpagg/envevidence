# 技术结构

[English](ARCHITECTURE.md)

仓库包含两个本地应用：Python＋Streamlit 文献证据工具 **EnvEvidence**，以及安卓实验手记 **EnvBench**。两者共用开源仓库，以导出流程组织数据，各自维护运行时存储。

## 电脑版证据流程

文献 `Project` JSON 保持 schema version 1，文档解析、模型适配、原句定位、人工核验和导出为独立模块。CLI 保持原有证据流程兼容。

`Workspace` schema version 1 保存语言与外观偏好，同时保留 0.2 的学习目标、任务和便签，使旧文件可原样读取与写回。文件位于数据目录的 `workspace/state.json`，不参与证据项目发现。

保存使用同目录临时文件、flush/fsync 与原子替换，读取或验证失败时保留原文件。同一项目使用一个编辑进程。

`ui.py` 提供入口，`workbench_ui.py` 负责侧栏与外观页，`evidence_ui.py` 负责证据流程。稳定 ID 用作控件键，逐次渲染的语言上下文改变界面文字而保留科研内容和审计记录。配色使用经过验证的十六进制颜色与应用 CSS，前景色按对比度选择。

OpenAI 与 Anthropic 适配器在界面确认发送或 CLI 使用 `--send-text` 后调用官方端点。每完成一项研究独立保存，模型原值与人工修订分别保留。

## 安卓实验手记

内置 HTML/CSS/JavaScript 通过 WebViewAssetLoader 运行。`lab-domain.js` 保存实验、计时、样品、水质与计算规则；`lab.js` 提供实验手记交互，`bench.js` 提供反应界面。Java 桥接私有存储、安卓时钟、闹钟、通知、相机／文件和 ZIP 操作。

Lab schema version 2 保存实验、计时器、计数器、现象、事件与样品。升级补齐样品审计字段并保留旧数据，旧版非空测量值标为来源未知，不追溯伪标为实测。

样品修订保留原数值、测量来源、时间间隔和理由。原始按钮事件的时间戳保持不变，修订后的实验时长用于取样偏差、拟合与辐照剂量。CSV 保持稳定机器字段名并增加审计列，完整 ZIP 保留全部历史和原始照片。

峰面积导入先验证整批数据，再统一应用。带编号与按顺序格式分别处理，错误保留原行位置。拟合使用正的、未排除的比值；排除保留理由，曲率只作为模型偏离诊断。

同一次设备启动期间使用安卓单调时钟，重启或换机后使用保存的系统时间恢复。导入的运行中计时器保持暂停。

## 数据边界

安卓实验功能在本机运行，照片与手记保存在私有目录。电脑版文献提取向所选服务发送解析文本与字段说明，密钥不写入项目 JSON。运行数据、API 密钥和私有签名材料排除在 Git 与源码包之外。

安卓手记与电脑版证据项目不直接同步；CSV 与 ZIP 用于明确的数据转移和备份。
