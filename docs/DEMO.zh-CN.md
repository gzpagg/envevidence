## EnvBench：从反应到样品导出

1. 安装安卓应用，进入 **我的 → 载入实验演示**，添加一组自制 UV/PDS 反应、样品、水质与现象记录，原有内容保持不变。
2. 打开演示反应，查看工艺、目标物、氧化剂剂量、取样点与水体基质。
3. 另建一个反应体验现场操作：安排取样时间，记录计划内或计划外样品，选择淬灭剂，为 pH、温度与体积标明来源。
4. 打开 **粘贴 LC 峰面积**，使用 `S-001 10000`、`S-002 8200` 等带编号数据，查看样品与数值的对应预览。插入一个无效行，确认修正后才可应用整批数据。
5. 查看 C/C₀ 与拟合时间范围；排除某点时填写理由。修订样品时间并填写说明，回看保留的原值。
6. 导出 **样品 CSV** 与完整 ZIP。CSV 含测量来源及原始／修订时间，ZIP 保留完整修订历史和照片。
7. 在 **我的** 中切换语言，确认应用文字变化，而样品名称与现象说明保持录入内容。

## EnvEvidence：从论文到核验记录

按 README 启动电脑版。新数据目录打开“文献证据”，默认英文、森林绿，可在侧栏切换“简体中文”。

1. 点击 **载入离线演示**，添加自制论文、补充材料与预录提取结果，不调用 API。
2. 打开 **证据核验**。Trial A 的污染物去除率为 85%，TOC 为 20%；Trial B 分别为 12% 和 2%；Trial C 的去除率为 64%，TOC 未找到。A/B 剂量来自补充材料。
3. 选择一个字段，对照引用原句及整页上下文，填写核验人与理由，保存核验记录。
4. 导出 CSV、Excel 或完整项目 JSON，查看模型原值、当前值与核验历史的对应关系。
5. 打开 **外观**，保存配色并重启；切换中英文，确认原文、模型结果与审计记录保持原始内容。

PDF、样品数据及预录结果均为自制、MIT 许可的示例。电脑版演示会校验资料哈希，公开截图使用独立的合成数据目录。

命令行演示：

```bash
python -m envevidence demo --output data/demo
```
