# 可复现演示

[English](DEMO.md)

按 README 启动应用。新数据目录直接打开“文献证据”，默认英文、森林绿；可先切换“简体中文”。

1. 点击“载入离线演示”，添加合成证据项目，不调用 API。
2. 打开“证据核验”。Trial A 的污染物去除率为 85%，TOC 为 20%；Trial B 分别为 12% 和 2%；Trial C 的去除率为 64%，TOC 未找到。A/B 剂量来自补充材料。
3. 对照出处核验一条字段，填写核验人与理由，保存并导出。文字匹配不能代替科学核验。
4. 打开“外观”，预览并保存配色，重启后配色保留。
5. 切换中英文，确认应用标签改变，而原文、模型结果和核验记录保持原样。

如果数据目录中有 0.2 版的学习目标、任务或便签，侧栏会显示保留条数；这些内容不显示，也不会被修改。

PDF 和预录结果为自制、MIT 许可的测试资料，演示会校验文件哈希，不调用真实模型。公开截图只使用独立演示目录。

命令行兼容演示：

```bash
python -m envevidence demo --output data/demo
```
