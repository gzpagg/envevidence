# 可复现演示

[English](DEMO.md)

按 README 启动应用。新数据目录默认英文、森林绿，四个模块全部开启；可先切换“简体中文”。

1. 点击“载入工作台演示”。程序追加自制学习目标、日期任务、置顶便签和合成证据项目，不覆盖已有数据；工作台示例只载入一次。
2. 在“学习进度”勾选一步，确认完成率由 1/3 变为 2/3；改名后完成状态保留。归档目标，开启“显示归档”，再恢复。
3. 在“日常进度”将待办改为已完成，再重新打开。逾期任务保留原日期，不计入今日分母。
4. 编辑、置顶、换色、保存便利贴，再归档与恢复。
5. 打开合成文献项目的“证据核验”。Trial A 的污染物去除率为 85%，TOC 为 20%；Trial B 分别为 12% 和 2%；Trial C 的去除率为 64%，TOC 未找到。A/B 剂量来自补充材料。
6. 对照出处核验一条字段，填写核验人与理由，保存并导出。文字匹配不能代替科学核验。
7. 在“外观与模块”预览、保存配色，隐藏和排序模块，重启检查持久化。恢复默认布局后，隐藏模块的数据应仍在。
8. 切换中英文，确认应用标签改变，而便签、原文、模型结果和核验记录保持原样。

PDF 和预录结果为自制、MIT 许可的测试资料，演示会校验文件哈希，不调用真实模型。公开截图只使用独立演示目录。

命令行兼容演示：

```bash
python -m envevidence demo --output data/demo
```
