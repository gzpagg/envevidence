# Third-party dependencies and data provenance

EnvEvidence's original code and synthetic fixtures use the repository MIT license. Dependencies are installed separately; their own notices and licenses continue to apply. No third-party scientific paper or research dataset is bundled.

Direct runtime dependencies:

| Component | Purpose | Upstream license |
| --- | --- | --- |
| Streamlit | Local web interface | Apache-2.0 |
| pypdf | Text-PDF parsing | BSD-3-Clause |
| Pydantic | Schema validation | MIT |
| HTTPX | HTTPS API requests | BSD-3-Clause |
| openpyxl | Excel export | MIT |

Development dependencies include pytest (MIT), ReportLab (BSD-style), build (MIT), and Ruff (MIT). Consult the installed distribution metadata for the exact versions and full notices. The lock file records the tested local environment, including transitive dependencies; it is not a license grant for those dependencies.

All PDFs in `envevidence/assets/` are generated by `scripts/build_demo.py` using invented data. Their expected results were specified as a software fixture, not validated as scientific findings. Do not cite them as publications.

OpenAI and Anthropic services require the user's own account and are governed by each provider's terms. This project is independent and does not imply endorsement or certification by either provider.
