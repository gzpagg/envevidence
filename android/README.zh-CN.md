# EnvEvidence 安卓实验助手 · 0.4.0 预览版

[English](README.md) · [电脑版文献工具](../README.zh-CN.md) · [截图与验证](../docs/ANDROID.md)

把手机用于实验现场：并行计时、计次、拍照、记录现象，并按实验回看时间线。主导航为 **实验、计时、记录、我的**；外观和设置统一放在“我的”，学习、任务和便利贴作为辅助工具保留。

## 安装

下载 [签名 APK](https://github.com/gzpagg/envevidence/releases/tag/v0.4.0-android-preview.1)，在 Android 8.0+ 手机上打开安装，并保持 Android System WebView 更新。与 0.3.0 使用相同的应用 ID 和签名，可以覆盖升级。卸载会删除本地数据，卸载前请导出完整备份。

无需账号、Python 或服务器。进入 **我的 → 载入实验演示**，可添加虚构的离线示例，不覆盖已有记录。实验功能不调用模型或 API。

## 做实验时怎样使用

1. **开始实验**：只需名称，样品标签和实验说明可选。
2. **添加计时**：秒表与倒计时可以并行，自定义名称和识别颜色，支持整组开始/暂停。数量没有人为固定上限，实际规模受设备内存与存储约束。分段、结束和归零均保留历史；倒计时到点后显示已超时多久。
3. **安排取样**：填写实验开始后的分钟数，例如 5、10、20、30。点击“已取样”时，实际时间与计划时间分别保存。暂停取样提醒不会顺延原始时间点，恢复时仍按实验开始时刻计算。
4. **计次**：大按钮 +1、撤销、新一轮计数；归零不删除历史操作。
5. **记录现象**：实验页直接拍照或写短句，自动关联实验、样品和已进行时长。文字修改保留前一版本；后来加入的照片有独立的加入时间，不将其冒充为原始拍摄时间。
6. **整理实验**：在时间线回看操作和现象；导出 CSV、单个实验 ZIP，或包含原始照片的完整备份。

## 计时提醒

进入 **我的 → 启用计时提醒**，允许系统通知及闹钟权限。权限未完整开启时会在界面提示。应用只安排最近一个到期的系统闹钟，到期后再安排下一个；同时到期的多个计时合并为通知。点击通知直接进入计时页，无需常驻后台服务。

同一次手机启动期间，使用安卓单调时钟计算已进行时长，应用重建或进程重新打开后可恢复。手机重启或数据迁移到另一台设备后，按保存的系统时间恢复，因此跨重启修改手机时间可能影响结果。导入备份中的运行中计时会暂停，避免旧提醒意外重新启动。

强行停止应用、关闭通知声音及厂商省电策略可能阻止提醒。已使用 Android 15 模拟器检查后台通知；实体机相机、长时间运行/重启场景及不同厂商省电策略仍需测试。本版本是预览版，不是校准计时仪器，也未上架 Google Play。

## 照片、备份与旧数据

- 调用系统相机或文件选择器，支持每张不超过 30 MB 的 JPEG、PNG 和 WebP。原始照片及其元数据保留；缩略图仅用于显示。
- 数据与照片保存在应用私有目录，关闭系统云备份和设备迁移备份；实验功能不上传照片或记录。
- 完整 ZIP 包含工作台 JSON、原始照片及预览图。单个实验 ZIP 仅包含该实验及其关联数据，不夹带其他学习记录或文献项目。
- 单次 ZIP 导出/恢复支持最多 512 MB 解压内容；较大的手记可按实验分批导出。导入只添加新的 ID，已有数据不覆盖；同一照片 ID 的内容冲突会明确报错。
- 从 0.3.0 升级时保留原有学习、任务、便利贴和证据记录。文献提取与核验转到电脑版，历史文献项目仍包含在完整备份中；仍可导入电脑版项目/工作台 JSON。
- 本次不加入 OCR、照片智能解读、语音识别、账号或云同步。

## 构建与验证

需要 JDK 17+、Android SDK 36 和 build-tools 35.0.0；已包含带校验值的 Gradle 8.13 wrapper。

```sh
cd android
./gradlew lintDebug testDebugUnitTest assembleDebug assembleRelease
cd ..
node --test android/tests/*.test.cjs
```

Windows 使用 `gradlew.bat`。[安卓自动检查](../.github/workflows/android.yml) 包含编译、逻辑测试和 Android 15 模拟器测试。发布包在本机用稳定私有签名签署；请私下备份签名密钥，后续升级需要同一身份。签名材料不进入 Git 或 APK。

界面由应用内置 HTML/CSS/JavaScript 显示，Java 负责原子保存、系统时钟、闹钟、通知、相机、文件选择及照片 ZIP。应用不加载远程网页；浏览器预览只验证界面，相机和后台提醒需在安卓中使用。

[验证记录](../docs/ANDROID.md) 区分已完成检查与未验证场景。界面采用暖白、陶土色、细线图标与简洁排版，保留 EnvEvidence 品牌。交互参考 [Time Timer](https://support.timetimer.com/hc/en-us/articles/29258432418203-Time-Timer-App-Free-vs-Paid-Premium-Features)、[LabArchives](https://help.labarchives.com/hc/en-us/articles/11729082137364-Adding-and-Editing-Entries) 和 [Claude Android](https://claude.com/blog/android-app)，无官方合作关系。
